# 导航与星图用球面纹理

六张图片从本项目 `assets/textures/` 的原有低分辨率纹理缩小得到，768 × 384，JPEG quality 88。继承原素材署名与课程展示用途，原始资料见 `assets/SOURCES.md`。文件映射、处理和 SHA-256 见本目录 manifest.json。

上游汇集：https://github.com/jeromeetienne/threex.planets/tree/master/images
原纹理：Planet Pixel Emporium，https://planetpixelemporium.com/planets.html

球体阴影、光环、黑洞示意、图标、星图航线与引力之门由 CSS/SVG 绘制；星云和深场缩略图复用 assets/odyssey 中已署名的观测影像。星球大小、路线、运动均为艺术编排。海王星沿用原项目传统蓝色纹理，不当作自然色实拍。
